Wiedisync for Android

The member app of KSC Wiedikon · Die Mitglieder-App des KSC Wiedikon

Install

  1. Install F-Droid (or Droid-ify / Neo Store).
  2. Add this repository: on your phone tap the button, or scan the code.

    Add to F-Droid
  3. Search for Wiedisync and install it. Updates arrive through F-Droid.
  4. For notifications, also install Sunup or ntfy from F-Droid, then turn notifications on in Wiedisync.

Repository address

https://fdroid.kscw.ch/repo?fingerprint=@FINGERPRINT@

Check the fingerprint when F-Droid asks: it proves the apps come from KSC Wiedikon.

No F-Droid? Download the APK from GitHub releases (also works with Obtainium). Source code: GitHub (AGPL-3.0). iPhone and computers: open wiedisync.kscw.ch and add it to your home screen.
