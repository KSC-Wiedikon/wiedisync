- **2026-06-21** **Scorer official-contact — time-gated to ±1h of kickoff (prod).** Follow-up tightening of the entry below: coaches/TR were seeing the assigned official's contact for **all** their duty games at any time. Now restricted to the contact window **1h before the game's start time → 1h after**. Promoted dev `7c23bf1a` (cherry-pick) → prod `e776db7f`. Server (`scorer-contacts.js`): skip games outside `[start−1h, start+1h]` — Zurich wall-clock date+time → UTC instant via a DST-correct two-pass offset (unit-checked summer CEST/winter CET/date-as-Date/boundaries), so cross-team official contacts are only returned around the game. Frontend: `showContact` is now **per-game** — admins still see it on any game, coaches/TR only in-window (also gates own-team officials whose contact is already in the base roster query); `useOfficialContacts()` polls every 60s so contact appears/disappears as the window opens/closes. **No schema/permission change** ⇒ `ext:deploy:prod` only. Build (tsc -b) green; prod endpoint live-checked (`401` unauth). **prod**: pushed `e776db7f` (CF Pages auto-deploy) + `npm run ext:deploy:prod` (directus-kscw restarted, smoke ✓).

- **2026-06-21** **Scorer official-contact visibility for coaches/TR (prod).** Promoted dev `372bb57c` (cherry-pick — dev↔prod are parallel histories) → prod `635c1ffc`. Assigned scorer/official email+phone, previously sport-admin-only, is now visible to coaches and team-responsibles **for games their team holds the scorekeeping duty for, and only those** ("only for that game"). Server-enforced by a new scoped read endpoint, not a Directus permission row (a per-game contact filter would hit the "deep filter + policy walk → silent empty" trap): `GET /kscw/scorer/official-contacts` resolves the caller's coached/TR teams, finds `type='home'` games where one owns a duty role, and returns `phone`/`email`/`hide_*` for just that role's assigned official (incl. delegated cross-team officials). No led teams → `{}`; raw-knex read, authz in code (coaches still can't bulk-read contacts via the items API); read-only ⇒ no audit. Frontend: `useOfficialContacts()` merges the scoped map onto member objects for `AssignmentEditor` (respecting `hide_phone`/`hide_email`), `showContact` true for leaders, duty-game visibility widened to coached/TR teams (staff-only coaches now see their team's duty games). **No schema/permission change** ⇒ no migration, no `setup-permissions.mjs` edit; `ext:deploy:prod` only (no `db:deploy`). Build (tsc -b) green; prod endpoint live-checked (`401 {"error":"Authentication required"}` unauth). **prod**: frontend pushed `635c1ffc` (CF Pages auto-deploy) + `npm run ext:deploy:prod` (directus-kscw restarted, smoke ✓). Live on dev since `372bb57c`.
